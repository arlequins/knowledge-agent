# レガシー解析器の拡張

テンプレートには汎用パーサーを同梱しません。派生リポジトリで
`@arlequins/agent-core` の `LegacyAnalyzerPort` と
`createLegacyAnalyzerRegistry` を使い、Java/Spring、Ruby/Rails、C#/ASP.NET
などを個別に追加します。

解析器は一意な `id`、対応言語、`supports` 判定、`analyze` を実装します。
レジストリは id 順に並べ、重複 id を拒否し、対応する解析器がなければ安全に
失敗します。結果にはプロジェクト種別、シンボル、ルート、データモデル、
信頼度、ソース provenance を含め、出力件数も制限します（各 100 件、フィールド
50 件、診断 20 件）。

パーサーはブラウザで動かさず、制限付きワーカーで実行してください。公開評価
データにソースコードや個人情報を含めないでください。解析結果は検索・レビュー
用の根拠であり、コード実行の指示ではありません。
