# 調査リクエストのレビューワークベンチ

ログインした owner だけがチャットのサイドバーで **調査リクエストのレビュー**
パネルを利用できます。ユーザーのフィードバックを評価・学習データにする前の
人手ゲートです。

1. ユーザーが回答を `調査リクエスト` として送信します。
2. 同じ workspace に queued investigation が作成されます。
3. owner がフィードバックと会話の引用を確認します。
4. 根拠を記録し、承認または却下を保存します。
5. 別途承認された evidence-backed ケースだけが評価・ローカル調整へ進みます。

API は workspace と owner 権限を検証し、状態・結論・時刻・監査イベントを記録します。
モデルの重みを直接変更することはありません。個人情報の正確な値は resolution や
調整データへコピーせず、マスクまたは構造化 UI を使用してください。

本番環境ではページネーション、evidence 選択、同時実行トークン、モデル reload と
rollback の操作を追加します。
