# 레거시 분석기 확장

템플릿에는 범용 파서를 넣지 않습니다. `@arlequins/agent-core`의
`LegacyAnalyzerPort`와 `createLegacyAnalyzerRegistry`를 이용하면 파생 레포에서
Java/Spring, Ruby/Rails, C#/ASP.NET 또는 다른 파서를 독립적으로 추가할 수
있습니다.

분석기는 고유한 `id`, 지원 언어, `supports` 판별 함수, `analyze` 함수를
제공합니다. 레지스트리는 id 순서로 실행 순서를 결정하고 중복 id를 거부하며,
지원 분석기가 없으면 안전하게 실패합니다. 결과는 프로젝트 종류, 심볼,
라우트, 데이터 모델, 신뢰도, 소스 provenance를 포함하고 출력량도 제한됩니다
(심볼/라우트/모델 100개, 필드 50개, 진단 20개).

파서는 브라우저에서 실행하지 말고 제한된 워커에서 실행합니다. 공개 평가
픽스처에 원본 코드나 개인정보를 넣지 마세요. 분석 결과는 검색·검토할 근거이지
코드를 실행하라는 지시가 아닙니다.
