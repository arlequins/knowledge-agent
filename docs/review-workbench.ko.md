# 조사 요청 검토 작업대

로그인한 소유자에게만 채팅 사이드바의 **조사 요청 검토** 패널이 보인다.
사용자 피드백이 평가·학습 데이터가 되기 전에 사람이 확인하는 게이트다.

1. 사용자가 답변을 `조사 요청`으로 표시한다.
2. 같은 workspace에 대기 중인 investigation이 생성된다.
3. 소유자가 피드백과 대화의 인용을 확인한다.
4. 근거를 적어 승인 기록 또는 반려 기록을 남긴다.
5. 별도로 승인된 evidence-backed 사례만 평가·로컬 튜닝으로 보낸다.

API는 workspace와 owner 권한을 모두 확인하고 상태·결론·시각·감사 이벤트를
기록한다. 이 기능은 모델 가중치를 직접 변경하지 않는다. 개인정보의 정확한
값은 resolution이나 튜닝 데이터에 복사하지 말고 마스킹·구조화 UI를 사용한다.

운영 환경에서는 페이지네이션, evidence 선택, 동시성 토큰, 모델 reload와
rollback 제어를 추가한다.
